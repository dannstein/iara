# Contexto do Projeto IARA e Preferências de Estilo

## 1. Arquitetura e Stack
- **Monorepo:** Frontend focado em Mobile-first usando React Native com Expo Router (`frontend-mobile`). Backend em Java 25 com Spring Boot e PostgreSQL (`backend-api`).
- **Objetivo:** Aplicativo de informação e ágil resgate para Defesa Civil.

## 2. Padrões de Código e Colaboração
- **Clareza e Modularidade:** Escreva código limpo, sem redundâncias e bem documentado. O desenvolvimento e a divisão de tarefas frequentemente envolvem trabalho em dupla (com o Dani), então a legibilidade para revisão cruzada é inegociável.
- **Rigor Lógico:** Seja extremamente preciso e metódico na lógica de programação. Ao lidar com regras de negócio complexas, fluxos de dados ou algoritmos, faça o passo a passo correto. Não use soluções "mágicas" ou atalhos que pulem etapas importantes da lógica.Faça um mapeamento rápido da estrutura de pastas deste monorepo. Identifique onde está a pasta do frontend-mobile, encontre o nosso arquivo de configuração de rotas (app/_layout.tsx), dê uma olhada no design da nossa tela de login (app/index.tsx) e leia o handout_doc.md para entender os perfis de acesso (GESTOR, TECNICO, DOADOR, etc).
- **Precisão Visual:** Siga as diretrizes de UI/UX à risca. Trate os assets de imagem e a interface com cuidado e nunca inverta as instruções de estilo, posições ou cores solicitadas pelo usuário.

## 3. Regras de Integração e API
- **Documentação como Lei:** SEMPRE leia e consulte o arquivo `handout_doc.md` para entender as regras da API, os perfis (GESTOR, TECNICO, DOADOR) e os endpoints antes de codificar.
- **Comunicação de Rede:** Nunca utilize `localhost` ou `127.0.0.1` nas chamadas do Axios no mobile. Use sempre o IP dinâmico configurado no arquivo `services/api.ts`.
- **Segurança:** O Token JWT deve sempre ser gerenciado com `expo-secure-store`.

## 4. Comportamento do Agente
- **Reaproveitamento:** Antes de criar um componente do zero (como botões ou inputs), verifique se já existe um componente customizado correspondente na pasta `@/components/` e reutilize-o.
- **Ações Destrutivas:** Sempre peça permissão clara antes de apagar arquivos ou sobrescrever lógicas complexas que já estejam funcionando.
